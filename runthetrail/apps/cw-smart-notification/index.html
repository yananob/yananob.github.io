CWスマート通知

Chatworkの未読メッセージをスマートに通知するAndroidアプリ

大勢が参加するグループチャットや夜間・休日の通知に疲れていませんか？『スマート通知 for Chatwork』は、Chatworkの未読メッセージをバックグラウンドで定期確認し、自分宛ての重要メッセージのみを精緻にフィルタリングしてシステム通知するAndroidアプリケーションです。

主な機能

自分宛てメッセージの抽出・フィルタリング

本文内の [To:account_id] や [rp aid=account_id] を認識し、自分宛てのメッセージのみを自動判定して通知します。引用記号 [qt]...[/qt] 内のメンションは自動スキップし誤通知を予防。自分からの送信メッセージ除外フィルターも搭載。

柔軟な通知抑止スケジュール設定

曜日タイプ（平日、休日・祝日、毎日）と時間帯（開始〜終了）の組み合わせによる抑止ルールを複数設定可能。抑止時間中もメッセージ同期・履歴保存はバックグラウンドで継続されるため、通知音やバイブのみを抑えて情報は逃しません。

定期バックグラウンド監視

Chatwork APIを活用して自分へのメンション（To/Reply）やダイレクトチャットをリアルタイム・定期的に監視し、必要な情報だけを逃さずキャッチできます。

通知履歴 ＆ ディープリンク

過去の通知履歴をアプリ内で確認でき、ディープリンクをタップすることでChatwork内の該当メッセージへ直接スムーズにジャンプできます。

セットアップ手順

1. Chatwork APIトークンの取得

本アプリの利用にはChatwork APIトークンが必要です。

  1. Chatworkにログインします。
  2. 右上のプロフィールアイコンをクリックし、「API設定」を選択します。
  3. パスワードを入力して「表示」をクリックし、生成されたAPIトークンをコピーします。

2. アプリの設定

  1. アプリを起動します。
  2. 初回起動時に通知権限の許可を求められた場合は許可します。
  3. 右上にある設定アイコン（歯車）をタップします。
  4. コピーしたトークンを「Chatwork API Token」項目に貼り付けます。
  5. 必要に応じて「Mentions Only（メンションのみ）」や「Quiet Hours（サイレント時間帯）」を設定します。
  6. 「Save（保存）」をタップして設定を完了します。
