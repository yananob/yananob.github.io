CWスマート通知

Chatworkの未読メッセージをスマートに通知するAndroidアプリ

Chatworkの未読メッセージを定期的に確認し、自分宛てのメンションや重要な更新をスマートに通知するAndroidアプリケーションです。

主な機能

定期ポーリング

15分ごとにChatwork APIをチェックし、新しい未読メッセージがある場合に通知します。

メンションフィルター

自分宛ての直接メンション（TO）や返信メッセージのみを対象に通知を行うようフィルター設定が可能です。

サイレント時間帯

夜間など、通知を受け取りたくない時間帯を指定して静かに保つことができます。

通知履歴機能

アプリ内で過去の通知履歴を確認し、ディープリンクを通じてChatwork内の該当メッセージへ直接ジャンプできます。

セットアップ手順

1. Chatwork APIトークンの取得

本アプリの利用にはChatwork APIトークンが必要です。

  1. Chatworkにログインします。
  2. 右上のプロフィールアイコンをクリックし、「API設定」を選択します。
  3. パスワードを入力して「表示」をクリックし、生成されたAPIトークンをコピーします。

2. アプリの設定

  1. アプリを起動します。
  2. 初回起動時に通知権限の許可を求められた場合は許可します。
  3. 右上にある設定アイコン（歯車）をタップします。
  4. コピーしたトークンを「Chatwork API Token」項目に貼り付けます。
  5. 必要に応じて「Mentions Only（メンションのみ）」や「Quiet Hours（サイレント時間帯）」を設定します。
  6. 「Save（保存）」をタップして設定を完了します。
